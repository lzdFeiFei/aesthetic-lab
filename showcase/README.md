# 作品展示

这个目录用于分享你的设计练习、代码实验和创意尝试。

## 目录结构

```
showcase/
├── experiments/          # 实验性项目
├── exercises/            # 练习作品
└── your-name/           # 个人作品集
    ├── project-1/
    │   ├── README.md
    │   ├── screenshot.png
    │   └── code/
    └── project-2/
```

## 展示模板

每个项目应该包含一个 README.md：

```markdown
# 项目名称

![预览图](screenshot.png)

## 项目信息

- **创作日期**：2024-01-20
- **灵感来源**：[链接或描述]
- **使用技术**：HTML, CSS, JavaScript, GSAP
- **学习目标**：练习滚动动效

## 项目描述

简单描述这个项目是什么，想要实现什么效果。

## 创作过程

### 灵感阶段
- 看到了什么
- 为什么想做这个

### 实现过程
- 遇到的挑战
- 如何解决的
- 学到了什么

### 反思
- 满意的地方
- 可以改进的地方
- 下次想尝试什么

## 在线预览

- [Demo 链接](如果有)
- [代码仓库](如果有)

## 参考资源

- [参考 1](链接)
- [参考 2](链接)
```

## 展示类型

### 1. 临摹练习

- 必须注明原作者和来源
- 说明临摹的目的（学习布局、色彩、动效等）
- 分享临摹过程中的发现

### 2. 原创实验

- 说明创作动机
- 记录实验过程
- 欢迎未完成的作品（标注"进行中"）

### 3. 技术探索

- 尝试新的库或技术
- 分享踩坑经验
- 提供代码示例

## 展示原则

### ✅ 鼓励

- 分享过程，不只是结果
- 记录失败和困惑
- 提供可运行的代码
- 说明学到了什么

### ❌ 避免

- 直接抄袭不注明来源
- 只放图片没有说明
- 过度包装，不真实

## 反馈文化

- 欢迎给他人作品提供建设性反馈
- 反馈时说明"为什么"
- 尊重创作者的努力
- 提问而不是批评

## 技术要求

- 代码应该可以运行（或说明如何运行）
- 如果有依赖，提供安装说明
- 图片不要太大（建议 < 1MB）
- 可以使用 CodePen、CodeSandbox 等平台

---

不要害怕分享"不完美"的作品。

每一次尝试都是进步。

开始你的第一个展示吧！
