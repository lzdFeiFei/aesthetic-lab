# Aesthetic Lab

> 从零开始培养艺术细菌  
> A long-term open experiment on cultivating aesthetic sense.

## What is this?

Aesthetic Lab is an open-source project that collects and organizes
diverse information related to aesthetics, design, art, and visual culture.

The goal is not to "teach art",
but to explore how aesthetic sense can be **cultivated** through:
- exposure to high-quality examples
- comparison and contrast
- structured observation
- long-term accumulation

**👉 [快速开始指南](GETTING_STARTED.md)** - 新手从这里开始

## What this project is NOT

- Not an art tutorial
- Not a design course
- Not a taste ranking system

This is an evolving knowledge base and experimental ground.

## Current Focus

- Curating references across different visual domains
- Exploring patterns behind "good-looking" things
- Building a structure that helps beginners grow aesthetic judgment

## 🤝 如何参与

这是一个协作项目，欢迎你：

- **分享资源**：发现好的设计网站、文章、工具
- **记录笔记**：在 `notes/` 目录下分享学习心得
