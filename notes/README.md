# 学习笔记

这个目录用于存放个人学习笔记。

## 目录结构

```
notes/
└── your-name/
    ├── 2024-01-topic-name.md
    └── 2024-02-another-topic.md
```

## 笔记模板

创建笔记时，可以参考以下模板：

```markdown
# 笔记标题

**日期**：2024-01-20
**来源**：[文章/视频标题](链接)
**标签**：#色彩 #排版 #动效

---

## 核心要点

- 要点 1
- 要点 2
- 要点 3

## 详细笔记

### 第一部分

内容...

### 第二部分

内容...

## 个人理解

这里写你自己的思考：
- 这个知识点让我想到...
- 我之前的理解是...现在发现...
- 可以应用在...场景

## 实践尝试

如果你尝试应用了这个知识：
- 做了什么
- 遇到什么问题
- 效果如何

## 疑问与待探索

- 还不理解的地方
- 想要深入研究的方向
- 相关的问题

## 相关资源

- [相关文章 1](链接)
- [相关文章 2](链接)
```

## 笔记建议

1. **真实记录**：不需要完美，记录真实的学习过程
2. **个人化**：加入你自己的理解和思考
3. **可检索**：使用标签，方便日后查找
4. **持续更新**：可以回来补充新的理解

## 分享笔记

- 笔记是个人的，但欢迎分享
- 如果你的笔记对他人有帮助，会被链接到主文档
- 不用担心写得不好，每个人的视角都有价值
