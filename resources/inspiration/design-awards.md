# 设计奖项与展示平台

> 获奖作品和优秀设计的集中地

## 奖项平台

- [CSS Design Awards](https://www.cssdesignawards.com/) - CSS 设计奖项
- [Awwwards](https://www.awwwards.com/) - 网页设计奖项
- [Site Inspire](https://www.siteinspire.com/) - 网站设计灵感
- [Dribbble](https://dribbble.com/tags/saas-landing-page) - 设计师作品展示

## 设计聚合

- [Muzli](https://muz.li/) - 设计灵感聚合器

## 如何使用这些平台

**不要只是浏览**，试试这样：

1. **主题式学习**：每周选一个主题（如"极简主义"、"渐变色运用"）
2. **对比分析**：找 3 个类似的设计，列出异同
3. **技术拆解**：思考"这个效果是怎么实现的"
4. **收藏系统**：建立自己的分类标签

## 警惕

- 不要陷入"只看不做"的循环
- 获奖作品不等于适合所有场景
- 关注设计背后的思考，而不只是视觉效果
