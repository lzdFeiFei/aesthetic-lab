## 📝 阅读建议

### 如果你是完全新手
1. 先读《美的历程》，建立对中国美学的基本认知
2. 再读《摄影构图艺术》，通过实践理解构图原理
3. 浏览《古代希腊艺术》PPT，感受西方古典美学

### 如果你想系统学习
1. 《詹森艺术史》+ 《牛津艺术史：中国艺术》- 东西方对照
2. 《西方哲学十五讲》- 理解审美的哲学基础
3. 结合 `notes/` 目录做读书笔记

### 如果你是技术背景
1. 《算法简史》- 从技术视角看历史
2. 《人工智能哲学》- 思考技术与人文
3. 《美的历程》- 补充人文素养
